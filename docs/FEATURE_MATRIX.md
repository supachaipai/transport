# แอพขนส่ง v1.0 — Feature Matrix

แอพรุ่นนี้เป็น Native Flutter Shell ที่เปิดระบบเว็บ v19 ด้วย session/cookie เดิม ดังนั้นสิทธิ์และหน้าจอที่มีอยู่ในเว็บยังใช้งานจากแอพได้โดยไม่ทำฐานข้อมูลซ้ำ

| ส่วนงาน | ใช้งานในแอพ |
|---|---|
| Login เดียวทุกฝ่าย | ✅ |
| Admin / งานขนส่งประจำวัน | ✅ |
| คนรถ / งานของฉัน | ✅ |
| เรียงลำดับงานคนรถ 1,2,3,... (v19) | ✅ |
| เริ่มวิ่ง / ปิดงาน + GPS | ✅ ขณะเปิดแอพ |
| โทร / LINE / Google Maps | ✅ เปิดแอพภายนอก |
| ถ่ายรูป / เลือกรูป / แนบไฟล์ | ✅ |
| ฝ่ายขาย | ✅ |
| ฝ่ายจัดซื้อ | ✅ |
| ฝ่ายดูแลระบบ / Backup | ✅ |
| ดาวน์โหลด Backup / เอกสาร | ✅ ดาวน์โหลดด้วย cookie session |
| ไทย / English / Myanmar | ✅ ตามเว็บเดิม |
| Background GPS ตอนดับหน้าจอ | ⏳ ยังไม่ใช่ใน v1 เพราะเว็บ v19 ส่ง GPS เมื่อหน้าเว็บทำงาน |
| Push Notification | ⏳ ต้องเพิ่ม API/FCM ในรุ่นถัดไป |
